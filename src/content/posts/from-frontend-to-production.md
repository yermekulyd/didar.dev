## Первый слой

Начинаю с понятного Next.js-сайта и локального контента. На этом этапе важнее структура, тексты и хороший пользовательский опыт, чем количество технологий.

## Дальше

- FastAPI для API и серверной логики.
- PostgreSQL для данных.
- Docker Compose для воспроизводимой разработки.
- CI/CD для проверок и деплоя.
- Linux VPS для понимания реального окружения.

## Почему Kubernetes не первый

Kubernetes имеет смысл после того, как я понимаю, что именно запускаю, как сервисы общаются между собой и что происходит с состоянием. Иначе он скрывает базовые проблемы вместо того, чтобы помочь их понять.
